# DBD Tournament Overlay

Aplicativo Windows para controle de overlay de torneios de Dead by Daylight no OBS.

## Uso
1. Baixe o instalador em **Releases**.
2. Instale e abra **DBD Tournament Overlay**.
3. No painel, clique em **Copiar URL**.
4. No OBS, adicione uma **Fonte de Navegador** em 1920 × 1080 e cole a URL.

A URL padrão é `http://127.0.0.1:8765/overlay.html` e funciona somente no computador em que o aplicativo está aberto.
